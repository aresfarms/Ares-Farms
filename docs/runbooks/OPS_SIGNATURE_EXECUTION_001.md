# OPS-SIGNATURE-EXECUTION-001

## Operating posture

Live execution and delivery are blocked. Only deterministic offline fixtures using `signature-mock-v1` may run. Test artifacts must state that they are not legally operative.

## Before every execution

Verify the exact source hash, clean malware result, supported PDF structure, transaction eligibility and counsel overlay, signer identity, separate signer capacity and authority, current disclosure and consent, exact affirmative intent, collision-free placement plan, exact-version human review, certified adapter, classification/residency/retention basis, healthy ledger/replay/outbox, and active scoped promotion. Unknown is denial.

## Unknown outcomes

Stop retries, move to `RECONCILIATION_REQUIRED`, preserve all evidence, query only through a certified idempotent reconciliation path, and require a recorded human decision. Never infer execution or delivery from a timeout.

## Validation and release

Reopen the produced PDF, confirm page geometry and expected page count, render every page, compare original-page appearance, verify the source and executed hashes, store the validation report and evidence bundle, then authorize release separately. Delivery and acknowledgment remain distinct events.

## Revocation and incident response

Authority revocation, consent withdrawal, document byte change, certification loss, clock failure, replay failure, or suspected disclosure immediately blocks new authorizations. Preserve artifacts and audit records; do not delete or overwrite execution evidence.
